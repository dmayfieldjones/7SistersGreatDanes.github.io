DNA data

Commercial tests

Results pending.
Commercial tests come from any company or registry: a DNA kit, an AKC DNA profile, a university lab. When results return, one claim is added: provider, kind of test, link, contributor. We store only the link and who added it, never the owner's report.
DNA kit: SNP arraypending

About 200,000 markers, not a whole genome. Labeled as an array so no one mistakes it for sequence.

AKC DNA profilelink only

The profile belongs to the owner. A member can add the AKC DNA number as a link, so others know a profile exists.

Sequence data

Research sequence from NCBI SRA, viewed in a genome browser. Nothing is shown until real data exists.

Whole-genome sequencenot yet

Raw reads go to NCBI SRA (shown here as an accession link). Processed CRAM and VCF sit in cloud storage, and the browser reads only the visible region.

How little we store

A claim is one short row. Names, roles and status live once in a small authors file that the page loads when it opens, so a change shows up everywhere without touching any claim. Heavy files stay in cloud storage and are referenced by link.
