# Deployment Guide for 7SistersGreatDanes.github.io

## Branch Structure

### `astro` / `main` branch (Source Code)
- **Purpose**: Contains your source code (Astro + React islands)
- **Location**: This is your working directory
- **Files**:
  - `src/pages/` - Astro pages (file-based routing)
  - `src/islands/` - React components hydrated client-side
  - `src/layouts/`, `src/components/` - Astro layouts and components
  - `src/lib/`, `src/utils/` - Shared helpers
  - `public/` - Static assets (images, CNAME file)
  - `package.json` - Dependencies and build scripts

### `gh-pages` branch (Deployed Site)
- **Purpose**: Contains the built static website (HTML, CSS, JS)
- **Location**: Automatically generated from the `out/` folder
- **Files**:
  - Static HTML files
  - Built JavaScript bundles
  - CNAME file (for custom domain)
  - All assets needed for the live site

## Deployment Process

1. **Make Changes**: Edit files in `src/`
2. **Commit Changes**: `git add . && git commit -m "Your message"`
3. **Push**: `git push origin astro` (or `main`, depending on your default branch)
4. **Deploy**: `pnpm deploy`
   - This runs:
     - `pnpm predeploy` → `astro build` - Builds the Astro site to `out/` (see `outDir` in `astro.config.mjs`)
     - `gh-pages -d out --nojekyll` - Pushes `out/` to the `gh-pages` branch
     - `pnpm postdeploy` → `git push --follow-tags`

## Important Files

### CNAME File
- **Location**: `public/CNAME`
- **Purpose**: Tells GitHub Pages which domain to use
- **Current Value**: `7sistersgreatdanes.com`
- **Important**: This file is copied to `out/CNAME` during build and deployed to `gh-pages`

### Build Output
- **Location**: `out/` folder (generated by `pnpm build`, configured via `outDir` in `astro.config.mjs`)
- **Purpose**: Contains the static files that get deployed
- **Note**: This folder is in `.gitignore` and should not be committed to source control

## Checking Deployment Status

### View deployed site:
- Visit: https://7sistersgreatdanes.com
- Or: https://dmayfieldjones.github.io/7SistersGreatDanes.github.io/

### Check what's deployed:
```bash
# See latest commit on gh-pages
git log -1 origin/gh-pages

# View deployed HTML
git show origin/gh-pages:index.html

# Check CNAME on deployed site
git show origin/gh-pages:CNAME
```

## Common Issues

### Changes not showing on live site:
1. **Browser Cache**: Clear cache or use incognito mode
2. **Deployment Delay**: GitHub Pages can take 1-5 minutes to update
3. **Wrong Branch**: Make sure changes are pushed to source and deployed to `gh-pages`

### CNAME Issues:
- Always update `public/CNAME` (not just root `CNAME`)
- The `public/CNAME` file gets copied to `out/CNAME` during build
- After changing CNAME, redeploy: `pnpm deploy`

## Workflow Summary

```
1. Edit files in src/
   ↓
2. Commit: git commit -m "message"
   ↓
3. Push: git push origin astro
   ↓
4. Deploy: pnpm build → pnpm deploy
   ↓
5. GitHub Pages serves from gh-pages branch
   ↓
6. Live site updates at 7sistersgreatdanes.com
```

## Notes

- **Never edit files directly in `gh-pages` branch** - they will be overwritten
- **`out/` is auto-generated** - don't edit it manually
- **Package manager**: pnpm is canonical (see `pnpm-workspace.yaml` and `pnpm-lock.yaml`). Don't reintroduce `package-lock.json` or `yarn.lock`.
